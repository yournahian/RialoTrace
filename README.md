# ⚡ RialoTrace

> **Proof of Work & Engagement Engine for Rialo Network** (The high-throughput network with configurable privacy for real-world finance).

RialoTrace quantifies and verifies community contributions, impressions, and viral discussions across X for **Rialo Network** (@RialoHQ).

---

## 🌟 Key Features

- **⚡ Rialo Proof of Work**: Real impressions generated by any contributor to Rialo Network across continuous cumulative series.
- **🏆 Best Post Spotlight**: Automatically highlights the user's highest-impact Rialo tweet with views, likes, and direct links to X.
- **🌟 Best Posts About Rialo**: Searchable catalog of ranked Rialo posts.
- **💎 Rialo Gems**: Leaderboard of core voices and researchers.
- **🎨 Rialo Aesthetic**: Deep void black (#010101), warm bone text (#E8E3D5), and ethereal pale mint accent (#A9DDD3).
- **🔒 FollowGate**: Access gate with follow verification for @yournahian on X.

---

## 🚀 Getting Started

```bash
npm install
npm run dev
```
Open [http://localhost:3001](http://localhost:3001) in your browser.
